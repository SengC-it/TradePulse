# Round-007 Gate Record

Round-007 uses the machine-readable gate record in `src/lib/research/selection-gates-round-007.ts`. It binds the five-candidate registry, the exact numeric gates, the six-fold improvement/catastrophic definitions, the sample/concentration/fee rules, the fixed model-integrity gate, and the inclusive scale-aware floating-point expectancy tie rule.

The canonical Gate SHA-256 is computed from the stable UTF-8 machine record. It is recorded in the authoritative output and manifest after the frozen implementation commit. Gate values are never derived from performance outcomes.
